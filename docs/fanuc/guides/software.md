# FANUC ENVIRONMENT

### ROBOGUIDE — il programma principale

Permette di creare una cella virtuale, importare modelli CAD, posizionare robot e attrezzature, programmare tramite il robot virtuale e verificare traiettorie, collisioni e tempi ciclo.
È la scelta più completa per progettazione e programmazione offline.



### ROBOGUIDE 3D Player — per visualizzare

Il nome indica uno strumento di riproduzione o visualizzazione 3D. È da distinguere dall'ambiente completo di programmazione: non darei per scontato che permetta di creare programmi, modificare celle o simulare tutte le funzioni del controllore.
Utile per consultare o presentare simulazioni già preparate, se queste sono supportate dalla versione installata.



### HandlingPRO Classic — per la movimentazione

È orientato alle applicazioni di handling: il robot prende un pezzo, lo sposta e lo deposita, oppure interagisce con macchine e trasportatori. Consente di verificare la fattibilità della cella e il ciclo di lavoro.
Ideale per pick-and-place, carico/scarico e movimentazione di componenti.



### MotionPRO Classic — per ottimizzare i movimenti

Analizza i dati di movimento e aiuta a ottimizzare i programmi TP secondo obiettivi quali riduzione del tempo ciclo, miglioramento della precisione del percorso, durata dei riduttori o consumo energetico.
È particolarmente interessante quando un programma funziona già, ma vuoi migliorarne le prestazioni.


### ROBOGUIDE Classic — per la compatibilità

È la famiglia tradizionale del software FANUC. Non va confusa con HandlingPRO e MotionPRO, che sono strumenti applicativi della stessa famiglia. FANUC continua a documentare una linea ROBOGUIDE Classic, distinta dalla nuova interfaccia ROBOGUIDE V10.
La scelta dipende dalla versione richiesta dal progetto, dai file esistenti e dalle opzioni di licenza.



### ROBOGUIDE SDK Docs — per chi sviluppa software

La sigla SDK significa Software Development Kit. Una voce denominata SDK Docs è normalmente documentazione tecnica per programmatori, non un ambiente di simulazione per l'operatore. Senza vedere il contenuto preciso della voce, non posso confermare quali API o funzionalità documenti nello specifico.
Da considerare se devi integrare ROBOGUIDE con un'applicazione personalizzata o sviluppare strumenti software.

## Riepilogo rapido

| Obiettivo | Comando |
|---|---|
| Controllare lo stato | `git status` |
| Vedere le modifiche | `git diff` |
| Aggiungere un file | `git add file.txt` |
| Preparare tutte le modifiche | `git add .` |
| Creare un commit | `git commit -m "Messaggio"` |
| Scaricare e integrare modifiche remote | `git pull` |
| Inviare commit a GitHub | `git push` |
| Scaricare informazioni remote | `git fetch` |
| Creare e cambiare branch | `git switch -c nome-branch` |
| Cambiare branch | `git switch main` |
| Integrare un branch | `git merge nome-branch` |
| Consultare la cronologia | `git log --oneline` |
| Togliere un file dallo staging | `git restore --staged file.txt` |
| Annullare un commit con un nuovo commit | `git revert ID` |
| Mettere da parte modifiche | `git stash` |
| Aprire il repository nel browser (CLI) | `gh repo view --web` |
| Elencare le Pull Request (CLI) | `gh pr list` |
